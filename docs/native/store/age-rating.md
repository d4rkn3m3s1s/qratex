# Yaş derecelendirmesi notları

Beklenen sonuç: **Apple 4+ / 9+**, **Google Play (IARC) PEGI 3–7 / Everyone**. Belirleyici konular aşağıda;
anketi doldururken bu cevapları kullanın.

| Soru (Apple / IARC) | Cevap | Gerekçe |
|---|---|---|
| Şiddet (cartoon/fantasy/realistic) | Yok / Seyrek-hafif karikatür | Mini oyunlar (ör. Core Defense, Star Hunt) soyut nişan/yakalama; kan, insan hedefi yok |
| Cinsellik, çıplaklık | Yok | — |
| Küfür, kaba mizah | Yok | Kullanıcı yorumları moderasyondan geçer (aşağıya bakın) |
| Alkol, tütün, uyuşturucu referansı | **Seyrek/hafif** | Mekân menülerinde/ürünlerde alkollü içecek adı geçebilir (bar/kafe). Hiç alkol satan mekân yoksa "Yok" |
| Simüle kumar (Simulated Gambling) | **Hayır — ama dikkat** | Günlük çark ve sürpriz kutu **parayla alınamaz**, ödülü nakde dönmez, yalnız ücretsiz günlük hak. Apple tanımında "simulated gambling" değil. Gelecekte puan/kutu satın alınırsa (IAP) bu cevap **değişir** ve ganimet kutusu oranlarını açıklamak zorunlu olur (App Store 3.1.1) |
| Gerçek para kumarı / yarışma | Hayır | Turnuva ödülleri puandır |
| Sınırsız web erişimi | Hayır | Harici bağlantılar sistem tarayıcısında açılır; WebView yalnız qratex.com'a izin verir (`allowNavigation`) |
| Kullanıcı tarafından üretilen içerik | **Evet** | Yorumlar, fotoğraflar, mekân yanıtları |
| Kullanıcılar arası iletişim | Sınırlı | Mekân ↔ müşteri yanıtları, ekip; serbest sohbet yok |
| Konum paylaşımı | Hayır | — |
| Dijital satın alma | Hayır | Uygulama içi satın alma yok |

UGC olduğu için iki mağaza da şunları ister (uygulamada mevcut olduğu doğrulanmalı):
1. Uygunsuz içeriği **bildirme** (yorum bildir), 2. kullanıcı **engelleme/gizleme**, 3. içerik politikası
(kullanım şartları) ve 4. 24 saat içinde müdahale taahhüdü. Apple 1.2 — eksikse ret sebebi.

Hedef kitle: 13+ (Play "Hedef kitle ve içerik" → 13–15, 16–17, 18+). Çocuklara yönelik değil; bu yüzden
"Families" programına girmeyin. KVKK/GDPR gereği 13 yaş altı hesap açılmamalı — kayıt formunda yaş
beyanı yoksa ekleyin.
