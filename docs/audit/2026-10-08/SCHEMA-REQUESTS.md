## veri-modeli (Dalga 3)

Kod tarafı kapatıldı (silme = arşiv/anonimleştirme, defter, mutabakat, soft-delete bekçisi); aşağıdakiler yalnız şema/göç ile kapanabilen kalıntılardır. Hepsi `prisma/migrations/<ts>_*/migration.sql` olarak, `IF NOT EXISTS` + `NOT VALID`/`VALIDATE` deseniyle (DEPLOY-RUNBOOK) yazılmalı.

- **Kayıt-sistemi FK'leri `Cascade` → `Restrict`** (B1 savunma derinliği): `Consumption.customer/dealer/card`, `ConsumptionReview.consumption/customer`, `RemedyOffer.feedback/consumptionReview/dealer/user`, `UserReward.reward/user`, `UserBadge.badge/user`, `UserQuest.quest`, `Donation.user/project`, `CardAuditLog.card`. Bugün bu cascade'ler UYKUDA (kullanıcı/QR/katalog/kart hiçbir yolda hard delete edilmiyor; `lib/data-safety`, `anonymizeUser`), ama DB seviyesinde garanti yok. Tek bilinçli istisna: `lib/dealer/kasa/server.ts` geri alma — yalnız değerlendirmesi OLMAYAN tüketimi siler (Restrict ile uyumlu).
- **`User.points` için `CHECK ("points" >= 0)`** (B3): bakiye yalnız `lib/points-wallet.ts` üzerinden değişiyor ve borç `points >= n` koşullu; CHECK son savunma hattı. Ön ölçüm: `SELECT count(*) FROM "User" WHERE points < 0` (0 değilse önce defterli düzeltme).
- **Para alanları `Float` → `Decimal(12,2)` (+ `currency String @default("TRY")`)** (B6): `Product.price`, `Consumption.amount`, `PricingPlan.price/pricePerBranch`, `Coupon.value/minPurchase`, `UserVIPStatus.totalSpent`, `CustomerLifetimeValue.totalSpent/avgOrderValue`, `HeatmapData.revenue`, `DealerFlashOffer.value`; `RemedyOffer.selectedValue String` → `Int` + `selectedUnit`. Göç: yeni sütun → `ROUND(x::numeric, 2)` doldur → kod yeni alana → eskisi düşer. (`DealerCustomerStats` zaten `Decimal(14,2)`.)
- **Ölü tablolar düşürülür** (B9; kod bağı bu turda kesildi): `OutboxEvent` (üreticisi yoktu; `lib/outbox.ts`, `outbox-process` ucu ve Komuta sağlık kontrolü silindi), `HeatmapData` (artık yazılmıyor; yoğunluk ekranı olay tablolarından TR saatiyle hesaplanıyor — `lib/pii-registry.ts` `business('HeatmapData')` satırı da kaldırılmalı), `DailyDealerStats` (yazan uç emekli, okuyan yok), `DealerFavoriteProduct`, `DealerOnboardingEvent`, `MenuItem`, `Theme` (hiç referans yok), `Session` (NextAuth `strategy: 'jwt'`; yalnız KVKK `deleteMany`). `FileUpload` ya bağlanmalı (tüm R2 yüklemelerinin kaydı + yetim temizliği) ya da düşmeli.
- **Index diyeti** (B8; `pg_stat_user_indexes.idx_scan` ile doğrulanarak, `CREATE/DROP INDEX CONCURRENTLY`): unique ile aynı tek-sütun index'ler (`User.email`, `QRCode.code`, `PhysicalCard.token`, `Coupon.code`, `ReferralCode.code`, `Page.slug`, `FeatureFlag.key`, `TeamTag.slug`, `ExperienceShareToken.token`, `ConsumptionReview.consumptionId`, `DealerStaff.userId`), composite öneki olan tek-sütun index'ler; index'siz FK'lere index (`CompanyTask.createdById/approvedById`, `TaskComment.authorId`, `TaskActivity.actorId`, `SquadBattleParticipant.squadId/userId`, `UserCosmetic.cosmeticId`, `ActionItem/Incident/CSMTask.assignedToId`, `DataSubjectRequest.userId` …); `AIEmbedding [dealerId, model, dimension, createdAt]`. `ApiKey.keyHash @unique` mimari-api bölümünde istendi.
- **FK'siz referanslara `@relation`** (B12): `CouponRedemption.userId/couponId`, `GameStreakClaim.userId`, `TournamentRewardClaim.userId`, `SeasonalChallengeClaim.userId/campaignId` (claim'lerde `onDelete: Restrict`), `PhysicalCard.batchId → CardBatch`, `SquadBattle.winnerId/challengedById`, `User.featuredCharacterBadgeId`.
- **Durum alanları enum** (B12): önce `RemedyOffer.status`, `Referral.status`, `SquadBattle.status`, `CompanyTask.status`, `Incident.severity` (bugün büyük/küçük harf karışık serbest string).
- **Kısmi unique index'ler** (B14): `AutomationJob(idempotencyKey) WHERE idempotencyKey IS NOT NULL AND status IN ('queued','processing','completed')` ve `UserAutomationRun(idempotencyKey)` — kod bu turda advisory kilitle yarışı kapattı; index son savunma. `AIThemeCluster.subTheme String @default("")` (NULL-distinct tuzağı; kod zaten `''` yazıyor). `InboxMessage.uidValidity Int?` + unique'e dahil (IMAP UID sıfırlanırsa yeni mailler atlanmasın).
- **`RemedyOffer` `CHECK (num_nonnulls("feedbackId","consumptionReviewId") <= 1)`** ve `Feedback.rating`/`ConsumptionReview.rating` `CHECK BETWEEN 1 AND 5`, `Feedback.npsScore CHECK BETWEEN 0 AND 10` (B14; Zod zaten var, DB savunma derinliği).
- **`datasource` yorumu** (B14): `schema.prisma` satır ~11 `connection_limit=1` diyor; ölçülmüş doğru değer 5 (bkz. perf notu). Yalnız yorum düzeltmesi.
- **Baseline göçü** (B4, operasyonel — ajan yapamaz): `prisma migrate diff --from-empty --to-schema-datamodel` → `0000_baseline`, canlıda `migrate resolve --applied`; ardından Neon dev branch'i. `npm run db:push` bu turda kapatıldı, `db:migrate` yalnız `QRATEX_DB_TARGET=dev` beyanıyla çalışır (`scripts/db-schema-guard.mjs`).

USING gin (lower("text") gin_trgm_ops)` — `Feedback.text`, `User.name/email/businessName`, `Product.name`, `QRCode.name`. `/api/search` `contains + insensitive` (ILIKE `%q%`) sorgularını sıralı taramadan kurtarır.

Ön ölçüm: `SELECT count(*), sum(pg_column_size(media)) FROM "Feedback" WHERE media::text LIKE '%data:image%'`. Backfill: her satırın data URI'lerini R2'ye `feedback/<qrId>/legacy-<id>-<n>.webp` (`MEDIA_KEY_PREFIX`) olarak yaz, `media`'yı URL dizisiyle güncelle (idempotent, parçalı).
